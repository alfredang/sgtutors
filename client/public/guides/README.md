# Lead magnet assets

The lead-magnet email links to:

    /guides/singapore-tuition-rate-guide.pdf

**This PDF is not in the repo yet.** Until it is added, the download link in the
rate-guide email will 404.

It is deliberately not auto-generated: the guide's value is real Singapore market
rate data (hourly ranges by level and by tutor type), and inventing those numbers
would mislead the parents it is aimed at. Source the rates from actual listings or
a market survey, then drop the PDF in this folder using exactly the filename above.

The email copy in `server/src/routes/leads.ts` promises three things — keep the PDF
consistent with them:

1. Hourly rate ranges for every level, from P1 to JC2
2. Part-time vs full-time vs ex-MOE tutor rates compared
3. Five questions to ask a tutor before you commit
